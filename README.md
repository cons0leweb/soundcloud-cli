SoundCloud CLI — быстрый полноэкранный TUI-клиент для публичного поиска, профилей, сетов и воспроизведения. С локальной сессией он также показывает персональные `Your Mix`, лайки и историю прослушивания.

> Неофициальный клиент, не связанный с SoundCloud. Используйте его в соответствии с правилами сервиса и правами авторов контента.

## Возможности

- поиск треков, исполнителей, профилей и жанров;
- просмотр треков пользователя, публичных лайков, сетов и плейлистов;
- персональные `Your Mix`, свои лайки и история прослушивания;
- раскрытие миксов и сетов в очередь треков;
- бесконечное радио по любому треку с рекомендациями SoundCloud, автопополнением и пропуском недоступных записей (`a`);
- автоматический переход по очереди, shuffle и три режима repeat;
- воспроизведение через headless `ffplay`;
- пауза, mute, громкость, остановка, следующий и предыдущий трек;
- экран горячих клавиш и адаптивная полоса прогресса;
- SoundCloud-style waveform: уникальная для каждого трека, движется при воспроизведении, замирает на паузе и скрывается клавишей `w`;
- управление только с клавиатуры;
- публичный режим без аккаунта и локальный авторизованный режим.

## Установка

### Готовый бинарник

Скачайте архив для своей платформы на странице [Releases](https://github.com/cons0leweb/soundcloud-cli/releases/latest), распакуйте `soundcloud` и поместите его в каталог из `$PATH`.

Linux x86_64:

```bash
curl -LO https://github.com/cons0leweb/soundcloud-cli/releases/download/v0.3.1/soundcloud_0.3.1_Linux_x86_64.tar.gz
tar -xzf soundcloud_0.3.1_Linux_x86_64.tar.gz
install -Dm755 soundcloud ~/.local/bin/soundcloud
```

Проверьте установку:

```bash
soundcloud --version
# soundcloud 0.3.1
```

### Из исходников

```bash
go install github.com/cons0leweb/soundcloud-cli/cmd/soundcloud@latest
```

Понадобятся:

- Go 1.23+ — только для сборки из исходников;
- [`yt-dlp`](https://github.com/yt-dlp/yt-dlp);
- FFmpeg с утилитой `ffplay`.

Ubuntu/Debian:

```bash
sudo apt install ffmpeg yt-dlp
```

macOS:

```bash
brew install ffmpeg yt-dlp
```

Готовые архивы выпускаются для Linux, macOS и Windows на `x86_64` и `arm64`. FFmpeg и `yt-dlp` не входят в архив и устанавливаются отдельно.

## Быстрый старт

Публичный поиск работает без настройки:

```bash
soundcloud
```

Начните вводить название трека, исполнителя или жанр и нажмите `Enter`.

### Варианты поиска

| Ввод | Результат |
|---|---|
| `deep house` | поиск треков |
| `@username` | треки профиля |
| `@username/sets` | сеты, плейлисты и миксы профиля |
| `@username/likes` | публичные лайки профиля |
| `https://soundcloud.com/...` | открыть ссылку на трек, профиль или сет |

## Авторизованный режим

Для доступа к своей медиатеке экспортируйте cookies SoundCloud в формате Netscape и передайте путь:

```bash
soundcloud --cookies ~/.config/soundcloud-cli/cookies.txt
```

Если рядом с бинарником есть `netscape.txt`, приложение подхватит его автоматически. Чтобы принудительно использовать публичный режим:

```bash
soundcloud --cookies=
```

Персональные миксы, лайки и история используют параметры авторизованного API из HAR. Приложение автоматически ищет самый свежий `soundcloud*.har` в `~/Downloads` и `~/Загрузки`, либо путь можно передать явно:

```bash
soundcloud --har ~/Downloads/soundcloud-session.har
```

Cookies и HAR читаются только локально. Они содержат доступ к сессии аккаунта: храните их с правами `0600`, никогда не добавляйте в Git и обновляйте после истечения сессии. Подробнее — в [политике безопасности](SECURITY.md).

### Как открыть персональный микс

1. Запустите клиент с актуальными cookies и HAR.
2. Нажмите `Esc`, чтобы выйти из строки поиска.
3. Нажмите `m` и выберите `Your Mix 1`.
4. Нажмите `Enter`: клиент загрузит полную очередь микса через авторизованный SoundCloud API.
5. Выберите трек и снова нажмите `Enter`.

SoundCloud использует разные форматы ID для контейнеров и треков. Начиная с `v0.2.0`, клиент понимает числовые, строковые ID и системные URN. Если API сообщает об истёкшей сессии, экспортируйте новый HAR.

## Очередь и воспроизведение

При запуске трека текущий список становится очередью. После завершения композиции клиент автоматически включает следующую.

Нажмите `a` на любом треке, чтобы запустить радио. SoundCloud подберёт похожие композиции, а клиент заранее пополнит очередь перед её окончанием — режим продолжает играть без ручного поиска.

- `Shuffle` выбирает следующий трек случайно, не повторяя текущий.
- `Repeat: выключен` останавливает воспроизведение в конце очереди.
- `Repeat: очередь` начинает очередь заново.
- `Repeat: один трек` повторяет текущую композицию.
- Выбранная громкость сохраняется при переходе между треками.

На Linux и macOS пауза физически приостанавливает процесс `ffplay` через `SIGSTOP/SIGCONT`. На Windows используется интерактивная команда самого `ffplay`.

## Управление

| Клавиша | Действие |
|---|---|
| `Enter` | поиск, воспроизведение или открытие сета |
| `a` | запустить бесконечное радио по выбранному треку |
| `w` | скрыть / показать визуальную волну |
| `↑` / `↓`, `j` / `k` | выбрать трек |
| `Space` | пауза / продолжить |
| `n` / `p` | следующий / предыдущий трек |
| `+` / `-` | изменить громкость |
| `x` | выключить / включить звук |
| `z` | случайный порядок |
| `r` | повтор выключен / очередь / один трек |
| `s` | остановить |
| `b` | вернуться из сета к предыдущему списку |
| `m` | персональные миксы |
| `l` | свои лайки |
| `h` | история прослушивания |
| `/` | вернуться к поиску |
| `Esc` | перейти между поиском и результатами |
| `q` / `Ctrl+C` | выйти |
| `?` | открыть справку по клавишам |

## Параметры

```text
--limit N          число результатов: 1–100 (по умолчанию 20)
--cookies FILE     Netscape cookie file, auto или пустое значение
--har FILE         HAR с авторизованной сессией
--yt-dlp PATH      путь к yt-dlp
--ffplay PATH      путь к ffplay
--version          версия приложения
```

## Разработка

```bash
make check
make build
```

Полная локальная проверка включает `go vet` и race-тесты. Релизный тег запускает GitHub Actions и публикует архивы вместе с `checksums.txt`:

```bash
git tag -a v0.3.0 -m "SoundCloud CLI v0.3.0"
git push origin v0.3.0
```

Архитектура разделяет ответственность по пакетам:

- `internal/soundcloud` — поиск, SoundCloud API и локальная сессия;
- `internal/player` — жизненный цикл `ffplay`;
- `internal/tui` — состояние, клавиши и рендеринг интерфейса.
